# Security and privacy

This project collects diagnostic information from a Windows PC. A generated ZIP
may contain information that should not be posted publicly, even after
best-effort redaction.

Do not include passwords, authentication tokens, cookies, private messages,
browser data, or unrelated personal files in an issue or pull request.

For a privacy or security flaw in the collector, use GitHub's private
vulnerability-reporting feature when available. Otherwise, open a public issue
that describes the affected collector field without including the sensitive
value or an unredacted diagnostic archive.

Crash dumps are excluded by default because they may contain fragments of
process memory. Keep them opt-in.
